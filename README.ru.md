# SOYUZ Microphones — открытые данные продуктов

📄 English version: [README.md](README.md)

Этот репозиторий содержит структурированные, публично доступные справочные данные о продукции **SOYUZ Microphones**, включая **студийные микрофоны**, **конденсаторные и динамические микрофоны**, а также **микрофонные предусилители**.

Цель репозитория — предоставить нейтральный, машиночитаемый и воспроизводимый источник технических данных, пригодный для:
- инженерного и сравнительного анализа;
- образовательных и исследовательских задач;
- использования в поисковых системах и ИИ-ассистентах.

Репозиторий **не содержит маркетинговых описаний** и **не раскрывает проприетарные методики измерений**.

## Структура данных продуктов

Каждый продукт располагается в собственной директории и содержит:

- `metadata.json` — структурированные метаданные продукта
- CSV‑файлы с данными частотной характеристики
- PNG‑изображения с графиками (при наличии)

### Пример

```
models/microphones/017_TUBE/
├── metadata.json
├── soyuz_017_tube_frequency_response.csv
└── soyuz_017_tube_frequency_response.png
```

## Данные частотной характеристики

Данные частотной характеристики (АЧХ) предназначены для технического анализа и
сравнительного изучения поведения микрофонов в слышимом диапазоне частот.

Частотные характеристики предоставляются как **относительные** данные.

Дополнительные примечания:
- Для большинства моделей микрофонов капсюли являются **съёмными / сменными** (см. `metadata.json` конкретной модели)
- Все субъективные, неколичественные описания явно помечаются как `subjective_non_quantitative`

### Формат CSV

CSV‑файлы имеют следующую структуру:

```
frequency_hz;response_db
```

- `frequency_hz` — частота в герцах (Гц)
- `response_db` — относительный уровень в децибелах (дБ)

### Совместимость с Excel

CSV‑файлы используют:
- разделитель столбцов `;`
- десятичный разделитель `,`

Это сделано для корректного открытия файлов в русскоязычных версиях Excel без
автоматического преобразования чисел в даты.

При использовании других инструментов (Python, R, MATLAB и т. д.) при
необходимости учитывайте формат разделителей.
